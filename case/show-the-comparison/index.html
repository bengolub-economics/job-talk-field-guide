Make the comparison visible.

When presenting several numbers, decide which comparison the audience should make. Arrange or plot the values so that comparison is easy to see.

Reworks before

A table can contain all the relevant evidence while making the audience search for the relationship you want to discuss. Organize the display around that relationship: put comparable quantities together, label their units, and use a common scale where appropriate. Keep the full table available for other comparisons.
